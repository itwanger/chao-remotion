# 小超的画面如何组织

画布为 1920 × 1080，30 fps。暖米色 `#f7f2e8` 做底，深墨色 `#232838` 写正文，蓝色 `#2150b4` 标当前对象，铁锈橙 `#b8532a` 用在变化或差异上，绿色只表示验证通过。截图和原始论文保留原色。

**读屏顺序。** 顶部保留主题名和章节条，中部只讲一个动作，底部放一行字幕和按章节时长分段的进度条。对象标签约 34 px，分组标题约 40 px，字幕约 39 px。上下留足距离，手机宽度下字幕与图中最下方的标签都要读得清。常见布局和颜色在模板的 `src/components/index.tsx` 与 `Scenes.tsx`。

**实测镜头。** 先用原屏幕建立位置，讲到入口、原句或数值时再取局部。以原图坐标同时移动图层和单色框，保留完整控件和四边余量。录屏和截图可放在 `MediaWindow`；`FigureFocus` 的取景比例由真实宽高决定。技术术语多时，把辨认对象需要的词留在画面上，让字幕和配音承担解释。

**机制镜头。** 例如讲前缀缓存，第一拍让两段相同的前缀对齐，第二拍取回已有 K/V，最后只计算新增部分。讲取消任务时，用同一个取消信号依次到达模型、工具和会话，分别显示终止状态。场景中的对象尽量延续到下一拍，直到需要给新对象腾地方。卡片适合表达分组，使用直角细蓝边和轻微的偏移阴影。

**节奏。** 转场用在换工作区、换证据或关系确实变化的地方。持续对照时保持外窗和主体位置。以实际配音为时钟，让视觉动作在词头附近开始，给观众留出读完结果的一拍；提示音与触碰或完成的那一帧对齐。
